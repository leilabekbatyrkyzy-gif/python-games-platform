# Python Games

Адаптивная игровая веб-платформа на HTML, CSS и JavaScript. Интерфейс на **қазақша / русском / English**, выбор языка сохраняется локально.

## Запуск

Требуется Python 3 (проверено на 3.12). Зависимости приложения отсутствуют.

```bash
cd /workspace/python-games-platform
python3 -m http.server 8000 --bind 0.0.0.0
```

Откройте сайт через HTTP на порту 8000 в своей среде разработки. Не открывайте `index.html` через `file://`: используются ES-модули.

## Возможности

- Главная страница, каталог, фильтры по жанру и поиск по текущему языку.
- Змейка: стрелки/WASD или экранные кнопки; столкновение завершает игру.
- Найди пару: 16 карт, 8 пар, счётчик ходов.
- Крестики-нолики: два человека на одном устройстве, победа и ничья.
- Модальное окно: перезапуск, закрытие кнопкой или Escape; очистка таймеров при выходе.
- Мобильная верстка, клавиатурная навигация, видимый фокус, уменьшение анимаций по системной настройке.

Игры сейчас реализованы на JavaScript. Python/Pygame-проекты нужно отдельно адаптировать и собрать для браузера: [инструкция](games/python/README.md), [архитектура и контракт адаптера](docs/architecture.md).

## Проверка

Браузерный сценарий использует Playwright и установленный Chromium. Приложение не зависит от них. В отдельном окружении можно установить Playwright без изменения файлов проекта:

```bash
npm install --prefix /tmp/python-games-tests playwright
NODE_PATH=/tmp/python-games-tests/node_modules node tests/smoke.cjs
```

Перед запуском проверки запустите HTTP-сервер на порту 8000. По умолчанию Chromium ожидается по `/usr/bin/chromium`; другой путь задаётся через `CHROMIUM_PATH`. Проверка охватывает языки и сохранение выбора, фильтры, поиск, завершение и перезапуск игр, мобильную ширину и ошибки браузера.
